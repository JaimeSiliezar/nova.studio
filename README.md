# Nova HTML Template

Plantilla responsive de landing page para un estudio creativo o pequeño negocio. Incluye HTML, CSS y JavaScript sin frameworks.

## Archivos

- `index.html` — estructura y contenido.
- `styles.css` — diseño, colores y adaptación a móviles.
- `script.js` — menú móvil y año automático del pie de página.

## Cómo abrirla

1. Extrae el ZIP en una carpeta.
2. Abre `index.html` en tu navegador.
3. Para editarla, abre los archivos con un editor como Visual Studio Code.

## Personalización antes de publicarla

1. Cambia “Nova Studio” por el nombre del negocio.
2. Actualiza los textos de servicios, proceso y contacto.
3. Cambia `hola@novastudio.example` por un correo real. El dominio `.example` es solo de demostración.
4. Ajusta los colores en las variables CSS al principio de `styles.css`.
5. Añade el aviso legal, privacidad y cookies que corresponda al negocio real.
6. Comprueba todos los enlaces y revisa la página en móvil y escritorio.

## Tecnología

HTML5, CSS3 y JavaScript vanilla. Google Fonts requiere conexión a Internet; si quieres que todo funcione sin servicios externos, elimina el `@import` de Google Fonts en `styles.css` y se usarán las fuentes de respaldo.
